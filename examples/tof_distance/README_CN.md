# ToF 实时测距示例

在 480 × 480 屏幕上分别显示左右两侧 VL53L0X 的测距数据。
可连接一块或两块 ToF 子板，EEPROM 描述必须有效，Board Type 为 `0x10`。
必要时使用 `module_eeprom_programmer` 写入描述。

## 功能概览

| 功能 | 说明 |
|---|---|
| 单／双侧实时测距 | 支持仅左侧、仅右侧或双侧接入；双侧保持开启、依次测量，独立显示距离与状态 |
| EEPROM 自动识别 | 根据有效的 ToF 类型描述发现子板，未插入时显示等待提示 |
| 自动分配地址 | 上电关闭两侧 XSHUT，识别后依次启动，左侧分配 `0x30`、右侧分配 `0x31`，复位后重新配置 |
| 左右分屏仪表 | 卡片与插槽对应，显示毫米距离、地址、状态、信号与环境光计数率，以及距离刻度条 |
| 双向挥手识别 | 根据两侧距离变化的先后顺序识别左挥／右挥，需要两侧都有有效读数 |
| 方向动画反馈 | 底部显示手势文字，12 段流水灯沿识别方向运动，动画独立于测距任务运行 |
| 快速采样与方向平衡 | 20 ms 单侧测量预算、交替采样顺序、采样时间及门限越过时间估算，减少漏检和方向偏差 |
| 分侧偏移补偿 | 左右均默认额外补偿 −37 mm，可独立配置；不是自动校准 |
| 异常与重连处理 | 某侧拔出或通信异常后独立清理、重新识别；无效测距清除旧数据，不直接当作拔出 |
| 调试与测试 | 提供距离、手势、实际采样率、两侧有效读数日志，以及主机端算法回归测试 |

### 快速体验

1. 插入一块或两块已写入有效 EEPROM 描述的 ToF 子板，按下文编译并烧录。
2. 查看对应卡片：出现有效距离表示该侧已开始测量；单侧也能测距，但不能识别左右挥手。
3. 使用手势功能时，让两侧朝向相同的操作区域，保持背景稳定，等待底部显示 `READY - WAVE LEFT OR RIGHT`。
4. 手从左侧传感器前移向右侧并完成距离恢复，应显示 `SWIPE RIGHT`，灯条向右运动；反向则显示 `SWIPE LEFT`，灯条向左运动。
5. 等待冷却及基线重新学习后再做下一次动作。方向按主板左右插槽定义，不随观察者站位自动翻转。

本示例只显示和记录手势结果，不会据此控制其他设备，也没有触屏交互、历史数据存储或自动校准功能。

## 硬件与地址分配

本示例专用于 ToF 子板，会在 EEPROM 识别前控制两侧的 XSHUT 引脚。
运行期间请勿在这两个插槽连接其他类型子板，以免影响其同位置引脚。
引脚映射使用 BSP，在指定主板上为：

| 插槽 | XSHUT | 传感器地址（7 位） |
|---|---|---|
| 左侧 | GPIO48 | 0x30 |
| 右侧 | GPIO47 | 0x31 |

应用启动时，先将两侧 XSHUT 拉低，再初始化显示和 EEPROM 发现服务。
某侧识别到有效 ToF 描述并取得插槽使用权后，仅开启该侧传感器，
通过默认地址 `0x29` 初始化，再分配为该侧地址。两侧初始化依次执行：
另一侧要么保持关断，要么已改址并保持开启。改址前检查目标地址冲突，
改址后探测新地址确认通信。EEPROM 地址不变。

两侧初始化完成后都保持开启。本示例使用驱动的高速模式，每侧测量预算为
20 ms，保留信号强度和 Sigma 有效性检查。一个任务依次对每个就绪传感器
执行一次阻塞式单次测量，再让出一个 RTOS tick（当前 100 Hz 下为 10 ms），
取消原先额外的 100 ms 等待。两次测量预算加让出时间约为 50 ms，实际还包含
轮询、I²C 和处理耗时，这不是实测采样周期。当前不使用 INT，通过 I²C 轮询等待结果。
初始化或重试期间，另一侧的刷新间隔可能暂时变长。

拔出或通信异常时，只清除对应侧显示，将该侧 XSHUT 保持为低电平，
销毁句柄并释放插槽。清理失败会保留使用权并定时重试，不使用阻塞式重试循环，
另一侧仍会继续被处理。重新插入时重新初始化和分配地址，不主动复位正常工作的另一侧。
无效测距本身不触发重连；仅状态码 0 的距离视为有效。

地址不永久保存，复位后需要重新分配。传感器意外掉电复位后，
程序在检测到测量失败时进入恢复流程。软件不能保证物理热插拔时的触点接通顺序。

## 界面与日志

顶部标题为 `ESP-MOSAICO TOF MODULE`，左右并排的两张卡片分别显示对应侧的数据：

- 插槽和传感器地址。
- 约 72 px 的距离数值，以及醒目的 28 px `mm` 单位。
- 测量或连接状态。
- 返回信号强度、环境光计数率，单位 MCPS，不是照度 lux。
- 0～2000 mm 水平刻度条；有效读数超出刻度时仍显示实际数值，刻度条停在最大位置。

测量无效时清除旧距离并显示状态码。屏幕触摸未启用，亮度为 80%。
屏幕数据更新间隔不短于 100 ms，识别到手势时立即更新；手势算法仍处理每组采样。
各侧有效数据日志限为每秒一次，包含插槽名称、距离、信号和环境光计数率。
每五秒输出 `Dual sampling: ... pairs/s`，可查看实际双侧成对采样率（包含无效读数）。

## 左右挥手识别

两个数据卡片下方增加手势识别区域，显示手势文字及 12 段流水灯条：

- 左侧先完成距离变化、右侧随后完成：显示 `SWIPE RIGHT`，灯条从左往右运动。
- 右侧先完成距离变化、左侧随后完成：显示 `SWIPE LEFT`，灯条从右往左运动。
- 结果保持约 2.5 秒，流水灯由 LVGL 定时器独立驱动，不依赖测距任务刷新。

使用前先让两个传感器对准稳定、有效的背景，连续取得三组稳定数据以学习基线。
然后在设定的时间窗口内完成一次挥手。提高采样速度后支持更短的变化脉冲，
但完全发生在两次采样之间的动作仍可能漏检。
这是简单的距离变化顺序判定，不是通用手部跟踪算法。

底部提示含义：

| 提示 | 含义 |
|---|---|
| `WAIT FOR TWO VALID TARGETS` | 缺少一侧有效距离，等待两个传感器都能测量 |
| `HOLD STILL - LEARNING BASELINE` | 保持背景稳定，等待基线学习／重新准备 |
| `READY - WAVE LEFT OR RIGHT` | 可以尝试左右挥手 |
| `SWIPE RIGHT` / `SWIPE LEFT` | 最近识别出的动作；显示期间不代表一直处于可触发状态 |

识别规则：

- 默认距离变化达到 **60 mm** 才开始记录脉冲，回到距基线 **30 mm** 内认为脉冲完成。
- 支持“变大再变小”，也支持手靠近时的“变小再恢复”；两侧变化方向须相同，开始和结束顺序须一致。
- 从第一个脉冲开始到两个脉冲结束须在 **1500 ms** 内；开始时间至少相差 25 ms，单个脉冲至少持续 25 ms，识别后冷却 800 ms。
- 同时变化或顺序不明确不判定方向；无效测量、缺少子板或采样间隔超过 500 ms 会清除未完成的手势。
- 识别、拒绝或超时后重新学习基线。没有有效背景读数时，会显示等待提示，不做识别。
- 每轮交替左右采样顺序，以各侧测量起止时间的中点作为采样时间，并在相邻数据间线性估算越过门限的时刻，不再统一使用整轮结束时间。这用于减小顺序读取带来的方向偏差，不等于硬件同步采样。
- 起始顺序明确、结束时间相同时仍可识别；起始同时或顺序矛盾仍拒绝，同时检查每侧数据是否过期。
- 每五秒的 `Sample validity: left=... right=...` 日志可比较两侧有效读数数量；若差异明显，应检查安装朝向、背景和遮挡情况。

可在 `menuconfig → ToF Distance Demo` 中调整：

- `Gesture distance excursion threshold (mm)`：变化幅度门限。
- `Gesture completion window (ms)`：手势完成时间窗口。

对应配置项为 `CONFIG_TOF_GESTURE_THRESHOLD_MM`（默认 60，范围 20～500 mm）和
`CONFIG_TOF_GESTURE_WINDOW_MS`（默认 1500，范围 500～3000 ms）。回落门限自动取幅度门限的一半；25 ms 时间条件和 800 ms 冷却定义在 `main/tof_gesture.c`，不是菜单配置项。

降低幅度门限会更灵敏，也更容易误触发。手势功能不改变地址、校准补偿或 INT 使用方式。
缩短测量预算可能增加噪声或弱信号下的无效读数，需实机复测距离和手势效果。
60 mm 幅度门限、回落滞回、先后顺序检查和冷却仍保持有效。

在示例目录运行主机回归测试：

```bash
cc -std=c11 -Wall -Wextra -Werror -I main tests/test_gesture.c main/tof_gesture.c -o /tmp/tof_gesture_test
/tmp/tof_gesture_test
```

## 编译与烧录

使用支持 ESP32-S31 的 ESP-IDF 6.2 或更新版本，激活环境后从仓库根目录执行：

```bash
cd examples/tof_distance
idf.py build
idf.py -p PORT flash monitor
```

将 `PORT` 替换为实际串口。显示、电源、I²C 总线及插槽映射使用 BSP 接口。
硬件版本支持跟随 BSP（v1.0、v1.2；v1.1 使用 v1.2 映射），新增双侧功能仍需实机验证。

## 分侧距离偏移补偿

[ST 数据手册](https://www.st.com/resource/en/datasheet/vl53l0x.pdf)
（DS11555 Rev 6，第 3.3.2 节）建议在 100 mm 处进行 Offset 校准。
此前一块子板的用户实测为：100 mm 时读数 137 mm（136～139 mm），
200 mm 时读数 243 mm（242～246 mm）。

左右两侧默认均使用上述数据得到的 **−37 mm 补偿**。
这不代表第二块子板已经独立校准，其准确度仍需单独复测。
两侧仍可分别调整配置，配置按插槽区分，不与 EEPROM 身份绑定。

通过 `idf.py menuconfig → ToF Distance Demo` 分别设置：

- 左侧：`Left slot additional distance offset (mm)`，
  配置项 `CONFIG_TOF_DISTANCE_OFFSET_ADJUST_MM`。
- 右侧：`Right slot additional distance offset (mm)`，
  配置项 `CONFIG_TOF_DISTANCE_RIGHT_OFFSET_ADJUST_MM`。

每侧复位后，在其初始 Offset 上叠加补偿，并回读验证。补偿同时影响屏幕和日志，
保存在固件配置中，不写入 EEPROM/NVS；设为 0 可禁用额外补偿。
这属于手动补偿，不代表完成 ST 50 次采样自动校准或串扰校准。
请分别从每颗传感器光学表面量取 100、200、500 mm 复测，
不要将一块子板的补偿直接套用到另一块。

## 验证范围

当前功能已通过 ESP32-S31 编译。用户反馈板端可以识别挥手；随后针对快速动作和左右识别差异进行了优化，最新优化的实际识别率仍需复测。

主机回归测试覆盖双向脉冲、两种距离变化方向、重叠脉冲、结束时间相同、抖动、无效数据、超时、冷却、时间戳回绕，以及交替采样下的不同相位。模拟相位测试中左右各 12/12 通过，这不是实机成功率。

实机验收建议：测试双侧同时上电、仅单侧插入、左右分别拔插和独立地址日志；分别验证距离补偿；在相同路径、速度与背景下各做多次左右挥手，结合 `Sample validity` 和 `Dual sampling` 日志比较效果。物理安装、背景反射和动作速度仍会影响识别。
